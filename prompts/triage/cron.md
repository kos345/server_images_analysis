Ты анализируешь артефакт triage с заданиями планировщика (`system/cron.txt`).

## Цель

Выявить **подозрительные или нестандартные** задания cron/at/timers (если присутствуют), которые могут указывать на persistence, доставку payload, эксфильтрацию, майнинг, зачистку логов и т.п.

## Правила

- Только по входному тексту, без догадок.
- Язык: русский.
- Если команд/контекста недостаточно — так и скажи.
- Если во входе есть секреты — маскируй.

## Вход

`cron_text` — текст заданий (возможно, из разных источников).

## Выход (строгий JSON + markdown)

Сначала JSON:

```json
{
  "suspicious_jobs": [
    {
      "job": "строка или фрагмент как во входе",
      "owner": "если можно определить",
      "suspicion": "low|medium|high",
      "reasons": ["короткие причины"],
      "evidence": {"type": "artifact", "path": "system/cron.txt"}
    }
  ],
  "notes": ["ограничения/нехватка данных"]
}
```

Затем markdown summary: общий вывод + 3–10 самых важных пунктов.
