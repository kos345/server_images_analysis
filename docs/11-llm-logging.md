# Правила логирования LLM запросов/ответов (каркас)

Цель: обеспечить воспроизводимость, аудит и защиту от “галлюцинаций”, не утекать секретами и чувствительными данными.

## 1) Где логировать

Минимум 2 уровня:

1) **Общий лог приложения** (например `logs/forensic.log` или `triage/<run>/logs/agent.log`):
   - метаданные вызова (без полных текстов)
2) **Run-scoped артефакты LLM** (например `triage/<run>/logs/llm/`):
   - запрос/ответ (полный или ограниченный по размеру), отдельно по шагам

## 2) Что логировать для каждого вызова LLM

- `run_id`
- `node` (например `triage_summaries.services`, `triage_summaries.cron`, `graph_rag_analyst`)
- `prompt_key` (например `system_services`) и путь к файлу промпта
- `prompt_hash` (sha256 от текста промпта) и/или `prompt_version`
- `model` (например `GigaChat-2-Max`) и параметры (temperature, max_tokens, etc.)
- `input_artifacts` (пути triage-файлов, которые были поданы на вход)
- размеры: `request_chars`, `response_chars` (или tokens, если есть)
- `latency_ms`
- результат: `success=true/false`, при ошибке — тип/сообщение

## 3) Чего нельзя логировать (или нужно редактировать)

- API ключи и токены: `IPINFO_TOKEN`, `VIRUSTOTAL_API_KEY`, `GIGACHAT_CREDENTIALS`, `TELEGRAM_*`, пароли Neo4j
- приватные ключи (PEM, OpenSSH private key) — заменять на `[REDACTED_PRIVATE_KEY]`
- полные хеши из `/etc/shadow` — по умолчанию маскировать (например оставлять тип хеша и первые/последние N символов)
- любые строки, похожие на секреты (JWT, AWS keys, etc.) — редактировать по regex

## 4) Формат хранения (рекомендация)

В `triage/<run>/logs/llm/`:

- `calls.ndjson` — по одной записи на вызов (метаданные)
- `requests/<call_id>.txt` — текст запроса (опционально, может быть обрезан)
- `responses/<call_id>.txt` — текст ответа (опционально, может быть обрезан)

## 5) Баланс “полнота vs безопасность”

- По умолчанию хранить **метаданные + ограниченные excerpts**.
- Полные запросы/ответы хранить только при наличии политики хранения и контроля доступа.

## 6) Связь с промптами triage

Каркас промптов и ключи находятся в `prompts/triage/` и реестре `prompts/triage_prompts.py`.
